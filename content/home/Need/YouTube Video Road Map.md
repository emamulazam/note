# How to Learn Machine Learning in 2026 (Roadmap)
*Based on the video tutorial by [Boris Meinardus](http://www.youtube.com/watch?v=yKeNBjo_lJU)*

---

## Step 1: Learn Python (The AI-Assisted Way)
Focus on reading, understanding, and debugging code rather than memorizing syntax from scratch.

* **Tools:** AI Coding Assistants (e.g., Claude Code, Cursor) + IDE Debuggers.
* **Approach:**
  1. Set up your local environment to run Python code.
  2. Prompt an AI tool to build a starter project (e.g., a simple Calculator app).
  3. Step through every line using an IDE debugger and inspect variables (lists, dictionaries, loops, conditional statements).
  4. Build small, fun projects (e.g., Snake game, simple personal website) with AI writing the bulk of the code.
  5. Practice debugging issues (e.g., local host networking, dependency errors) by discussing them with the AI.

---

## Step 2: Essential Math Fundamentals
Focus on intuitive understanding and practical application over theoretical proofs.

* **Core Topics:**
  * **Calculus:** Derivatives and integrals.
  * **Linear Algebra:** Vectors, matrices, and matrix operations.
  * **Probability Theory:** Core concepts, particularly Bayes' Rule.
  * **Math Utility Rules:** Log rules, summation notation, etc.
* **Core Resource:**
  * Book: *Why Machines Learn*
  * Supplementary Videos: 3Blue1Brown (Linear Algebra), StatQuest (Probability)
* **The AI Study Loop:**
  1. Read a section of the book (e.g., Gradient Descent).
  2. Ask an LLM to clarify confusing parts with simple examples.
  3. Prompt the LLM for practice problems starting from easy to hard.
  4. Work through problems and have the LLM verify your solution and explain errors.

---

## Step 3: Classical Machine Learning
Master core ML techniques, evaluation metrics, and basic pipeline design.

* **Topics:** Logistic Regression, Decision Trees, Recommender Systems, Training Strategies.
* **Core Course:**
  * *Andrew Ng’s Machine Learning Specialization* (Coursera / YouTube)
* **Learning Workflow:**
  * Complete the course lecture modules and hands-on coding assignments.
  * Prompt an LLM to generate end-to-end Python pipelines for algorithms.
  * Ask interactive follow-up questions about loss functions, hyperparameter choices, and training mechanics.

---

## Step 4: Deep Learning (Choose Your Path)

Choose between an **Applied Path** (fast track to building products) or a **Research Path** (deep theoretical grounding for top-tier research/engineering roles).

### Path A: The Applied Path (Focus on Building)
* **Course:** Andrew Ng’s *Deep Learning Specialization*.
* **Transformers & LLMs:**
  * Stanford *CS25: Transformers United* (YouTube).
  * Andrej Karpathy's YouTube tutorials (specifically *Building GPT from Scratch* / *nanoGPT*).
* **Project Workflow:**
  * Break down complex architectures (data loader, tokenizer, transformer blocks, training loop) iteratively with an AI coding partner.

### Path B: The Research / Deep Understanding Path (Focus on Theory)
* **Core Resource:** *Understanding Deep Learning* (Book & Free PDF).
* **Study Loop:**
  1. Read a chapter in the book.
  2. Watch visual explanations (3Blue1Brown, StatQuest) or ask an LLM for clarification.
  3. Have an LLM write a toy implementation of the model architecture to examine.
  4. Practice book exercises and ask the LLM to generate customized quiz questions.

---

## Step 5: Hands-On Projects & Experience

Apply knowledge through empirical, practical work:

1. **Kaggle Competitions:**
   * Start with beginner datasets.
   * Use AI for Exploratory Data Analysis (EDA) and boilerplate code to focus on model design and problem-solving.
2. **Paper Implementations:**
   * Pick an ML/Deep Learning research paper at an appropriate difficulty level.
   * Read existing reference implementations.
   * Re-build the codebase line-by-line using AI to explain complex segments.

---

## Bonus Step: Public Build & Research Sharing
* **Document Progress:** Write blog posts or share insights on platforms like X (Twitter) or LinkedIn.
* **Publishing:** Write up your work in paper format to publish on arXiv, or aim for submissions to major conference workshops.
